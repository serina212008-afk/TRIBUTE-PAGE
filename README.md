# TRIBUTE-PAGE
With a basic understanding of HTML and CSS, this project focuses on creating a tribute page dedicated to a person I admire. The page highlights the individual’s life, achievements, and the qualities that inspire me the most.The webpage includes well-structured paragraphs, images, and an appealing layout to make the content visually engaging. Different font styles, background colors, and CSS styling techniques are used to enhance readability and design.
This project helped me practice core web development skills such as HTML structure, CSS styling, layout design, and content presentation, making it a perfect beginner-friendly project.
